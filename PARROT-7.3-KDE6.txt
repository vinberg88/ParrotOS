Parrot Security (ParrotOS, Parrot) is a Free and Open source
GNU/Linux distribution based on Debian Stable designed for
security experts, developers and privacy aware people.
It includes a full portable arsenal for IT security and
digital forensics operations. It also includes everything
you need to develop your own programs or protect your privacy
while surfing the net. Parrot is available in three main 
editions, Security, Home and Architect Edition, even as
Virtual Machine (Virtual Box, Parallels and VMware), on
Raspberry Pi and also on Docker and WSL for Microsoft.
The first public release ParrotOS appeared on April
10th, 2013 as the result of the work of Lorenzo

Fix IP problem for X410. Cant find screen problem. Look for ip adress.

OPEN POWERSHELL AND TYPE: ipconfig

NOTE - Importent to look for ip-adress. Last lines are IP-numbers for WSL in POWERSHELL so x410 works.

SAVE IP FROM POWERSHELL HERE, YOU NEED IT LATER IN INSTALLATION OF MATE DESKTOP: 172.30.16.1

NOW GO BACK TO Parrot OS 7.3 Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip-number for WSL here and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

Visual studio code from Microsoft - Install via ParrotOS 7.3

sudo apt-get install wget* gpg* -y
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" |sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
rm -f packages.microsoft.gpg

sudo apt install apt-transport-https* http* -y
sudo apt update
sudo apt install code -y
