Copy and Paste in terminal and enable systemd

sudo nano /etc/wsl.conf

and change systemd to true

[boot]
systemd=true

----------------------------------------------

Set password for root and user. You will be glad you did this for ParrotOS

sudo passwd root

sudo passwd adolf  <-- change adolf to your name.

Update Parrot Security 7.3 - GNOME

sudo apt update && sudo apt full-upgrade -y

-----------------------------------------------------

Dbus problem fix =) install all. You will get an error but we fix that i next step. THIS WILL TAKE SOME TIME...

sudo apt install systemd dbus-* dbus-broker* dbus-daemon* dbus* systemd-resolved -y

----------------------------------------------

Fix THIS error for PARROT OS 7.3

Job for dbus-broker.service failed. See "systemctl status dbus-broker.service" and
"journalctl -xeu dbus-broker.service" for details.

Copy and paste in terminal. ONE BY ONE NO STRESS...

sudo systemctl disable --now dbus-broker.service

sudo systemctl enable --now dbus.service

sudo systemctl restart dbus.service

Visual studio code - Install for Parrot Security 7.3- ParrotOS 7.3

sudo apt-get install wget* gpg* -y
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" |sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
rm -f packages.microsoft.gpg

sudo apt install apt-transport-https* http* -y
sudo apt update
sudo apt install code -y

Last lines is WSL ip. Save IP from powershell here: 172.30.16.1

Now go back to Parrots OS Terminal - Parrot Security 7.3

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here Powershell and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
