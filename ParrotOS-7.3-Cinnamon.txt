About ParrotOS - https://parrotsec.org - Parrot SEC - 2026

Parrot Security (ParrotOS, Parrot) is a Free and Open source
GNU/Linux distribution based on Debian Stable designed for
security experts, developers and privacy aware people.
It includes a full portable arsenal for IT security and
digital forensics operations. It also includes everything
you need to develop your own programs or protect your privacy
while surfing the net. Parrot is available in three main 
editions, Security, Home and Architect Edition, even as
Virtual Machine (Virtual Box, Parallels and VMware), on
Raspberry Pi and also on Docker and WSL for Microsoft.
The first public release ParrotOS appeared on April
10th, 2013 as the result of the work of Lorenzo Faletra who
continues to lead development.

About Cinnamon from Mint - https://linuxmint.com/rel_zena_whatsnew.php

Cinnamon is a free and open-source desktop from Linux Mint.
environment for Linux and other Unix-like operating systems,
which was originally based on GNOME 3, but follows traditional
desktop metaphor conventions. Cinnamon is a Linux desktop that
provides advanced innovative features and a traditional user
experience. The desktop layout is similar to Gnome 2 with
underlying technology forked from Gnome Shell. Cinnamon makes
users feel at home with an easy-to-use and comfortable desktop 
experience.

Paste in terminal and enable systemd for ParrotOS.

sudo nano /etc/wsl.conf 

and add

[boot]
systemd=true

---------------------------------------

Update All its time

sudo apt update && sudo apt full-upgrade

-----------------------------------------------------

Dbus problem fix =) install all. You will get an error but we fix that i next step. ParrotOS 7.3 and Cinnamon desktop.

sudo apt install systemd dbus-* dbus-broker* dbus-daemon* dbus* systemd-resolved -y

----------------------------------------------

Fix THIS error for Parrot OS 7.3 and Cinnamon Desktop.

Job for dbus-broker.service failed.
See "systemctl status dbus-broker.service" and "journalctl -xeu dbus-broker.service" for details.

Copy and paste in terminal. ONE BY ONE NO STRESS for ParrotOS 7.3

sudo systemctl disable --now dbus-broker.service

sudo systemctl enable --now dbus.service

sudo systemctl restart dbus.service

----------------------------------------------

Reboot ParrotOS - Reboot ParrotOS - Reboot ParrotOS

----------------------------------------------

Fix IP problem for X410. Cant find screen problem. Look for ip adress.

OPEN POWERSHELL AND TYPE: ipconfig

NOTE - Importent to look for ip-adress. Last lines are IP-numbers for WSL in POWERSHELL so x410 works.

SAVE IP FROM POWERSHELL HERE, YOU NEED IT LATER IN INSTALLATION OF MATE DESKTOP: 172.30.16.1

NOW GO BACK TO Parrot OS 7.3 Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip-number for WSL here and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed Parrot OS 7.3 and Cinnamon desktop =]

Install visual Studio Code for ParrotOS.

Copy and paste to install Visual Studio Code for ParrotOS

echo "code code/add-microsoft-repo boolean true" | sudo debconf-set-selections

sudo apt-get install wget gpg
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" |sudo tee /etc/apt/sources.list.d/vscode.list > /dev/null
rm -f packages.microsoft.gpg

sudo apt install apt-transport-https
sudo apt update
sudo apt install code
